# 🥗 AI 다이어트 기록장

먹은 음식을 **문장으로 적기만 하면** 내장 AI 엔진이 음식과 양을 알아내 칼로리와 탄·단·지를 계산해 주는
다이어트 기록 웹앱입니다. 몸무게·운동도 함께 기록하고, 남은 칼로리에 맞춘 식단과 운동을 추천받을 수 있습니다.

설치할 것도, 서버도, 회원가입도 없습니다. `index.html` 파일을 브라우저로 열면 바로 동작합니다.

## ✨ 기능

| 기능 | 설명 |
|---|---|
| 🍚 **AI 식사 기록** | `쌀밥 한 공기, 김치찌개 1인분, 계란 2개` 처럼 적으면 음식·수량을 추출해 칼로리를 계산 |
| ⚖️ **몸무게 기록** | 날짜별 체중 저장, 직전 기록과 비교, 목표 체중까지 남은 기간 예측 |
| 🏃 **운동 기록** | `달리기 30분, 스쿼트 4세트` → MET 공식으로 소모 칼로리 계산 |
| 🎯 **목표 칼로리** | 키·몸무게·나이·활동량으로 BMR / TDEE / 하루 목표 칼로리 자동 계산 |
| 🍽️ **식단 추천** | 남은 칼로리에 맞는 18종 식단 템플릿 중 단백질이 높은 순으로 추천 |
| 🔥 **운동 추천** | "300kcal 태우려면 각 운동을 몇 분 해야 하는지" 표로 계산 + 주간 루틴 |
| 📖 **운동 방법 백과** | 22종 운동의 동작 순서·요령·부상 주의사항 |
| 📉 **통계** | 몸무게 변화 그래프, 섭취 vs 소모 막대그래프, 전체 기록 표 |
| 🔐 **구글 로그인** | 사람마다 자기 계정으로 로그인해 각자의 기록을 갖고, 여러 기기에서 이어서 사용 (설정 필요) |
| 💾 **백업** | JSON 파일로 내보내기 / 가져오기 |

## 🚀 실행 방법

### 1. 가장 간단한 방법
`index.html` 파일을 더블클릭하면 브라우저에서 바로 열립니다.

### 2. 로컬 서버로 열기 (권장)
```bash
cd diet-tracker
python -m http.server 5588
```
브라우저에서 <http://localhost:5588> 접속.

### 3. 인터넷에 올리기 (GitHub Pages)
아래 [GitHub에 올리는 법](#-github에-올리는-법) 참고. 올리면 휴대폰에서도 접속할 수 있습니다.

## 🧠 "AI"는 어떻게 동작하나요?

외부 API나 인터넷 연결 없이, 브라우저 안에서 도는 **규칙 기반 자연어 처리 엔진**(`js/ai.js`)입니다.

1. **문장 분리** — 쉼표·`+`·"그리고"·"이랑" 등으로 음식 단위를 나눕니다.
2. **수량 추출** — `1인분`, `한 공기`, `반 공기`, `200g`, `3조각`, `곱빼기`(×1.5) 같은 표현을 숫자로 바꿉니다.
3. **음식 매칭** — 92종 음식 DB(`js/food-db.js`)와 비교합니다.
   완전 일치 → 포함 관계 → **2-gram 유사도(Dice 계수)** 순으로 점수를 매겨 오타도 어느 정도 잡아냅니다.
4. **영양 계산** — 1인분 기준 값에 수량 배수를 곱해 칼로리·탄수화물·단백질·지방을 산출합니다.
5. **DB에 없는 음식**은 "확인 필요" 표시와 함께 추정값을 넣고, 사용자가 칼로리를 직접 고칠 수 있게 합니다.

### 사용하는 공식

```
BMR (Mifflin-St Jeor)
  남성: 10×체중(kg) + 6.25×키(cm) − 5×나이 + 5
  여성: 10×체중(kg) + 6.25×키(cm) − 5×나이 − 161

TDEE = BMR × 활동계수(1.2 ~ 1.9)

운동 소모 칼로리 = MET × 3.5 × 체중(kg) ÷ 200 × 운동시간(분)

체지방 1kg ≈ 7,700kcal
```

## 🛠️ 내 입맛대로 고치기

### 음식 추가하기
`js/food-db.js`에 한 줄 추가하면 끝입니다.

```js
{ n:'마라탕', a:['마라샹궈'], u:'인분', g:600, k:700, c:60, p:30, f:38, t:['국물','매운','고열량'] },
```

| 키 | 뜻 |
|---|---|
| `n` | 음식 이름 |
| `a` | 별칭 배열 (이렇게 적어도 인식됨) |
| `u` | 기본 단위 (`인분`, `개`, `공기`, `조각` …) |
| `g` | 1단위의 무게(g) — `200g` 처럼 적었을 때 환산에 사용 |
| `k` `c` `p` `f` | 1단위 기준 칼로리 / 탄수화물 / 단백질 / 지방 |
| `t` | 태그 (`다이어트`, `단백질`, `고열량` … 추천에 사용) |

### 운동 추가하기
`js/exercise-db.js`에 추가합니다. `met` 값은 [Compendium of Physical Activities](https://pacompendium.com/)에서 찾을 수 있습니다.

```js
{ n:'클라이밍', a:['암벽등반'], met:8.0, type:'스포츠', part:'전신',
  how:['준비운동을 충분히 한다.','팔이 아니라 다리로 밀어 올린다.'],
  tip:'악력보다 체중 이동이 중요하다.',
  warn:'손가락 건초염에 주의.' },
```

## ⚠️ 주의

- 칼로리 값은 **추정치**입니다. 조리법에 따라 ±20% 이상 차이 날 수 있습니다.
- 성장기 청소년은 하루 섭취량을 기초대사량(BMR) 아래로 내리지 않는 것이 좋습니다.
  이 앱도 목표 칼로리가 BMR의 85% 아래로는 내려가지 않도록 막아 둡니다.
- 의학적 조언이 아닙니다. 급격한 체중 변화나 건강 문제가 있다면 전문가와 상담하세요.

## 🔐 여러 사람이 각자 쓰기 (구글 로그인)

기본 상태는 **로컬 모드** — 기록이 그 브라우저에만 저장됩니다.
Firebase를 연결하면 **구글 로그인**이 켜져서, 사람마다 자기 계정에 기록이 저장되고
휴대폰·PC 어디서 로그인해도 같은 기록을 이어서 쓸 수 있습니다.

설정은 **[FIREBASE.md](FIREBASE.md)** 를 따라 10분이면 끝납니다 (무료, 카드 등록 불필요).
설정 전에는 로그인 버튼 자리에 "로컬 모드"라고 표시되고, 앱은 그대로 잘 동작합니다.

동작 방식:

- 로그인하면 `users/{내uid}` 문서 하나에 내 기록 전체가 저장됩니다.
- 보안 규칙(`firestore.rules`)이 **자기 문서만** 읽고 쓰도록 막아, 남의 기록은 볼 수 없습니다.
- 기록은 항상 브라우저에도 함께 저장되므로, 인터넷이 끊겨도 계속 쓸 수 있습니다.
- 여러 기기의 기록은 **합쳐집니다.** 끼니·운동은 고유 id로 중복을 걸러냅니다.
- 한 컴퓨터를 여러 사람이 써도 계정별로 분리 저장되어 섞이지 않습니다.

## 🔒 개인정보

로컬 모드에서는 모든 기록이 **내 브라우저의 localStorage**에만 저장되고 어디로도 전송되지 않습니다.
로그인해서 쓰는 경우에는 내 Firebase 프로젝트(구글 클라우드)에만 저장됩니다.
브라우저 데이터를 지우면 로컬 기록은 사라지니, 통계 탭의 **JSON 내보내기**로 가끔 백업해 두세요.

## 🐙 GitHub에 올리는 법

자세한 단계별 설명은 **[GITHUB.md](GITHUB.md)** 에 따로 정리해 두었습니다.
요약하면:

```bash
cd diet-tracker
git init
git add .
git commit -m "AI 다이어트 기록장 첫 커밋"
git branch -M main
git remote add origin https://github.com/<내아이디>/diet-tracker.git
git push -u origin main
```

그 다음 GitHub 저장소의 **Settings → Pages → Branch: main / (root)** 를 선택하면
`https://<내아이디>.github.io/diet-tracker/` 주소로 휴대폰에서도 쓸 수 있습니다.
